Quickstart
==========

Installation
------------

:tsl:`tsl` supports Python 3.8 through 3.11. It requires a compatible
:pytorch:`null` `PyTorch <https://pytorch.org/>`_ and :pyg:`null` `PyG <https://www.pyg.org/>`_ stack to be
installed first. The PyG stack comprises ``torch-geometric``, ``torch-scatter``,
and ``torch-sparse``; it is intentionally not installed automatically because
the correct wheels depend on the selected PyTorch and accelerator builds.

Quickstart with uv
++++++++++++++++++

The following creates a development environment. Select the matching PyG
command from the `PyG installation guide
<https://pytorch-geometric.readthedocs.io/en/latest/install/installation.html>`_
after PyTorch has been installed; it supplies the compiled extensions matching
your exact Torch and CUDA/MPS/CPU build.

.. tab-set::

   .. tab-item:: Unix and macOS

      .. code-block:: bash

         uv venv --python 3.10
         source .venv/bin/activate
         UV_TORCH_BACKEND=auto uv pip install torch
         # Install torch-geometric, torch-scatter, and torch-sparse using the
         # command generated by the PyG installation guide. Example:
         # uv pip install torch-geometric==2.5 torch-scatter torch-sparse -f https://data.pyg.org/whl/torch-${TORCH}+${CUDA}.html
         uv pip install torch-spatiotemporal

   .. tab-item:: Windows PowerShell

      .. code-block:: powershell

         uv venv --python 3.10
         .venv\Scripts\Activate.ps1
         $env:UV_TORCH_BACKEND = "auto"
         uv pip install torch
         # Install torch-geometric, torch-scatter, and torch-sparse using the
         # command generated by the PyG installation guide. Example:
         # uv pip install torch-geometric==2.5 torch-scatter torch-sparse -f https://data.pyg.org/whl/torch-${TORCH}+${CUDA}.html
         uv pip install torch-spatiotemporal

To install the latest development version instead of the latest stable release, run the following command:

.. code-block:: bash

    uv pip install git+https://github.com/TorchSpatiotemporal/tsl.git

.. admonition:: NumPy compatibility
   :class: caution

   If an existing environment shows ``_ARRAY_API not found`` or the message about
   a module compiled with NumPy 1.x, reinstall NumPy below version 2, then restart
   the Python process:

   .. code-block:: bash

      uv pip install --reinstall "numpy<2"


Installing using conda
++++++++++++++++++++++

.. tip::

    Using conda allows to automatically solve PyTorch and PyG dependencies,
    choosing the latest CUDA version available supported by the system.

To install :tsl:`tsl` using conda, clone the repository, navigate to the library root
directory and create a new conda environment using the provided conda configuration:

.. code:: bash

    git clone https://github.com/TorchSpatiotemporal/tsl.git
    cd tsl
    conda env create -f conda_env.yml

Then, activate the environment and install :tsl:`tsl` using :code:`pip`.

.. code:: bash

    conda activate tsl
    pip install -e .

.. note::

   Installation of :tsl:`tsl` directly from conda is on the roadmap!
